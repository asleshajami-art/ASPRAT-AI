# ASPRAT AI 🤖

ASPRAT AI is an AI-powered chat application that uses Google's Gemini AI
to generate intelligent and interactive responses to user questions.

## 🚀 Features

- AI-powered conversations
- Intelligent responses using Google Gemini AI
- React-based user interface
- Backend API built with Node.js and Express
- TypeScript support
- Environment variable configuration for API security

## 🛠️ Technologies Used

### Frontend
- React
- TypeScript
- Vite

### Backend
- Node.js
- Express.js
- Google Gemini AI API

## 📁 Project Structure

ASPRAT-AI/
├── client/       # Frontend application
├── server/       # Backend API
└── README.md     # Project documentation

## ⚙️ Setup and Installation

### Prerequisites
- Node.js and npm
- Google Gemini API key

### 1. Clone the Repository

git clone https://github.com/asleshajami-art/ASPRAT-AI.git

### 2. Set Up the Frontend

cd ASPRAT-AI/client
npm install
npm run dev

### 3. Set Up the Backend

Open a separate terminal:

cd ASPRAT-AI/server
npm install

Create a `.env` file inside the `server` folder and add:

GEMINI_API_KEY=your_gemini_api_key

Start the backend using the appropriate script configured in `server/package.json`.

## 🔐 Security

Keep your Gemini API key private. Never commit your `.env` file or expose
your API key in frontend code.
